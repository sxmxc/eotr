# Echoes of the Rift

**Echoes of the Rift** is a tactical deckbuilding roguelite set in a fractured dimension where technology and magic collide. Traverse shifting rift maps, build powerful decks, battle enemies across a grid-based battlefield, and uncover the story behind the chaos.

## ✦ Features

* **Tactical Grid Combat**: Positioning matters. Battle enemies on a tile-based battlefield.
* **Deckbuilding Mechanics**: Customize your deck with powerful attacks, skills, movement, and utility cards.
* **Dynamic Rift Maps**: Navigate procedurally generated maps where every node leads to new encounters and decisions.
* **Corruption System**: Corrupted tiles are impassable zones that change the terrain and force new strategies.
* **Relics and Resource Management**: Equip game-changing relics and manage in-run resources to stay alive.

## 🎮 Gameplay Overview

* **Tile Types**: Includes resource, corrupted (impassable), and special effect tiles.
* **Card System**: Every card has a cost, type, and effect. Synergize to build powerful strategies.
* **Enemies**: Unique AI patterns per enemy type; study and counter their moves.
* **Battle Flow**: Draw cards, play actions, reposition, and end your turn strategically.
* **Map Navigation**: Between battles, choose paths across the Rift map toward the final floor.

## 🛠️ Tech Stack

* **Engine**: Godot 4.x
* **Language**: GDScript
* **Architecture**: Scene-based modular design with custom UI systems and animation states.

## 🚀 Getting Started

1. Clone the repo:

   ```bash
   git clone https://github.com/your-username/echoes-of-the-rift.git
   ```
2. Open the project in [Godot 4](https://godotengine.org/).
3. Press **Play** to launch the game.
