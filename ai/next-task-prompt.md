# Starting a backlog session

Use this prompt when asking an agent to select and implement the next task:

> Read AGENTS.md, ai/README.md and ai/workflows/development.md. Inspect
> ai/planning/todo.yaml and recent handoffs, then choose the highest-value ready,
> unblocked task within the requested scope. Verify old assumptions against code.
> Implement a cohesive change, run bounded relevant checks and update the task's
> tracking plus affected authoritative docs. Report what changed, evidence and
> remaining limits. Preserve user work and existing gameplay/presentation contracts.
> Do not commit, push or deploy unless separately requested.

For a specific task, state it directly instead of selecting backlog work.
