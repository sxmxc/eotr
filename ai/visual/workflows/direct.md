# Direct workflow

1. Use discovery and baseline artifacts; inspect game art references directly. State the event's emotional and mechanical message in one sentence.
2. Write ai/visual/specs/<event>.md with source references, baseline evidence, focal hierarchy, silhouette, palette/value plan, material behavior, motion trajectory, anticipation/contact/recovery choreography and sound/camera coordination. Design this event specifically; do not assign it to a fixed effect category.
3. Apply staging, contrast, acceleration, follow-through and purposeful secondary motion. Explain why each layer helps source/target/state readability. Consider both a single execution and overlapping effects in the battlefield.
4. Define measurable acceptance evidence: which frames/phases should change, what must remain readable, how long residuals may last, and which gameplay outcomes must match. Distinguish artistic intent from facts observed in the baseline.
5. Select the smallest justified native implementation. Direction is reviewable in the spec; honor any user approval requirement already in force, otherwise continue within the requested scope. Do not ask the developer to diagnose VFX or supply professional art direction.
